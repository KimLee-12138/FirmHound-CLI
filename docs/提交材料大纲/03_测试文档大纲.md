## 1. 测试目标

- 验证 CLI 可以在本机和 CI 环境安装、启动、自检。
- 验证计划、分析、状态、恢复等核心命令逻辑正确。
- 验证固件/rootfs 能生成完整报告和结构化产物。
- 验证缺少外部工具时系统降级而不崩溃。
- 验证安全策略能阻止未授权、越界路径、危险命令、公网目标和危险 payload。
- 验证历史 CVE fixture 和真实固件样本可用于回归。

## 7. 漏洞发现能力测试

### 7.1 CVE fixture 回归

验证点：

- CVE fixture 的 candidate/verdict/attack_surface 符合 Schema。
- 命令注入类 CVE 能被规则识别为高风险。
- 溢出类 CVE 能被危险函数和输入源识别。

### 7.2 真实固件 AC15

现有结果：

- 解包完成。
- rootfs 评分 10，confidence 1.0。
- 发现 645 个静态候选。
- Top verdict 中多条集中在 `bin/httpd` 和 `/goform/formWifiConfigGet`。
- 当前结论是 `NEED_DYNAMIC` 静态候选，不等同已确认漏洞。

### 7.3 真实固件 OpenWrt WE826

现有结果：

- 解包完成。
- rootfs 评分 8，confidence 1.0。
- 发现 357 个攻击面条目。
- 发现 166 个二进制。
- 未生成高风险候选。

### 7.4 真实固件 BE3LPro

现有结果：

- offset `0x204` 出现 OpenSSL encryption, salted。
- 文件内 `Salted__` 头确认。
- UNPACK 阶段中止，提示需要密钥/密码/解密材料。

## 8. 外部分析器测试

### 8.1 SaTC

- 测 parser 是否能解析正常、空、截断、变体 grammar。
- 缺 Ghidra/Docker/angr 时应 skipped/degraded。

### 8.2 FirmRec

- 测 VULNS.md、PostgreSQL dump、危险 PoC 清洗。
- Blind Run 强制隔离，不进入统一候选。

### 8.3 KLEE

- 测 reachable witness。
- 测 infeasible 只写反证。
- 测 timeout/path explosion 不改变分数。

### 8.4 mini-BOND

- 测授权、私有 IP、baseline、安全 payload。
- 只有 `poc_sanitized=true` 的 trigger 可确认候选。
- simulation mode 不生成生产 finding。
